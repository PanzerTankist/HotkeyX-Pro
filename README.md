# HotkeyX Pro

**HotkeyX Pro** is a modern desktop application that lets you launch your favorite applications using custom global keyboard shortcuts.

Designed with simplicity and productivity in mind, HotkeyX Pro provides an intuitive interface for managing shortcuts, organizing applications, and accessing your tools faster.

## ✨ Features

- **Custom Global Shortcuts** — Create your own keyboard shortcuts to launch applications.
- **Application Scanner** — Automatically discover installed applications.
- **Manual Application Selection** — Add executable files manually.
- **Shortcut Recording** — Easily assign keyboard combinations.
- **Conflict Detection** — Identify shortcut conflicts.
- **System Tray Integration** — Keep HotkeyX Pro running in the background.
- **Persistent Settings** — Your shortcuts and preferences are saved locally.
- **Single Instance** — Prevent multiple application instances.
- **Modern Interface** — A clean, dark, Steam-inspired design.

## 🛠️ Built With

- Electron
- Node.js
- JavaScript

## 🎯 Purpose

HotkeyX Pro was created to make everyday computer usage faster and more convenient by allowing users to launch applications without searching through menus or navigating the desktop.
